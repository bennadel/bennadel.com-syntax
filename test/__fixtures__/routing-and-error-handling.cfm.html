For // aesthetic reasons, I'd like the URL for these post-back operations to remain the // same during the form processing life-cycle. This way, if we have to present an // error message to the user (after the form has been submitted), the URL is never // showing as "index.cfm"; but, rather, has the original URL of the page itself. It // might look and feel like one; but nothing can route directly into it.
